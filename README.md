# Kuravo

App de fichas de anamnese, pacientes e agenda para terapeutas e profissionais de bem-estar, criado pela **Nexvo Solution**.

- `app/` — código do aplicativo (web, usado tanto no Electron quanto no Capacitor)
- `mobile/` — projeto Android (Capacitor)
- `supabase/` — schema do banco (SQL)
- `.github/workflows/` — gera o APK Android automaticamente via GitHub Actions

Dados criptografados de ponta a ponta. Veja `GUIA-ANDROID.md` e `GUIA-SUPABASE.md` (enviados à parte) para instruções de uso.
